# 任务看板(Task Board)

一个**零依赖、免安装**的纯前端任务看板(Kanban)小工具。支持分块自由摆放、子任务层级编号、进度管理、输入联想、拖拽移动,自带浅色/深色主题。整个项目只有 4 个文件,拷走就能用。

## 🚀 安装指导

本项目是纯静态页面,**无需安装 Node.js、无需 npm install、无需构建**,三选一即可:

### 方式一:直接双击打开(推荐,最简单)

1. 把整个 `任务看板` 文件夹拷到任意位置(本机、U 盘、另一台电脑都行);
2. 双击 `index.html`,浏览器会自动打开;
3. 完成,开始使用。

> 推荐使用 Chrome / Edge / Safari / Firefox 的较新版本。

### 方式二:本地静态服务器(适合长期固定使用)

用系统自带的 Python 起一个本地服务:

```bash
cd /Users/ming-shen/Desktop/任务看板
python3 -m http.server 8000
# 浏览器访问 http://localhost:8000
```

或者用 Node:

```bash
npx serve /Users/ming-shen/Desktop/任务看板
```

优点:数据绑定在固定的「主机 + 端口」上,浏览器清缓存策略更可预期;也可以让同一局域网的设备访问(如 `http://192.168.x.x:8000`)。

### 方式三:部署到静态托管(多人/多设备访问)

整个项目就是静态文件,直接把文件夹内容上传到任意静态托管即可,**无需任何构建步骤**:

- GitHub Pages:推送到仓库 → Settings → Pages → 选择分支根目录;
- Vercel / Netlify:拖拽文件夹上传;
- 自己的服务器:拷贝到 Nginx/Apache 的静态目录。

部署后通过 URL 访问,所有数据仍保存在各人浏览器里。

## 🧳 数据与搬迁(重要!)

**数据不在项目文件夹里,而是保存在浏览器的 localStorage 中**(键名 `taskboard.v1`)。所以:

- 项目文件夹本身可以随便移动/拷贝/删除重建,程序随时可用;
- 但**换电脑、换浏览器、或清空浏览器数据后,看板内容不会自动跟着走**。

### 场景 1:换电脑 / 换浏览器(标准搬迁流程)

1. 旧环境:点顶栏 **「导出」**,得到 `任务看板-YYYY-MM-DD.json`;
2. 把这个 JSON 和项目文件夹一起拷贝(U 盘 / AirDrop / 网盘均可);
3. 新环境:双击打开 `index.html` → 点 **「导入」** 选择该 JSON → 数据完整恢复(含分块坐标、大小、子任务层级、进度)。

### 场景 2:把项目挪个位置(本机)

- 直接拖动/改名 `任务看板` 文件夹即可,程序零配置;
- Chrome/Edge/Firefox 对 `file://` 页面的 localStorage 通常按 `file://` 域共享,挪动后数据一般还在;**但 Safari 等浏览器可能按路径隔离**,若打开后发现是空的,用场景 1 的 JSON 恢复即可。

### 场景 3:使用本地服务器方式(方式二/三)

- 数据绑定「协议 + 主机 + 端口」:`http://localhost:8000` 和 `http://localhost:9000` 是两个独立的数据空间;
- 换端口或换域名后是"新"看板,用导入恢复;部署到线上则每台设备各自独立存储。

### 📌 备份建议

- 数据无价,**建议每周点一次「导出」**留存 JSON;
- 「导入」会整体覆盖当前数据,导入前请确认;
- 导入时程序会自动修复孤儿节点、循环引用等异常层级。

## ✨ 功能一览

- **分块(板块)**:白板式**自由摆放**——按住 ⠿ 拖到任意位置(第二行也行),松手即停;双击 ⠿ 自动整理成行列;支持新增、点击标题重命名、折叠、删除,每个分块独立配色。
- **任务三列展示**:任务内容是一行字符串 `A - B - C`,展示时按 `-` 自动拆成三列;列名(任务/负责人/备注)可点击修改。
- **单行编辑**:点击任务行,整行变为 `A - B - C` 单行输入框,**回车保存**(清空回车 = 删除),Esc 取消。
- **子任务与自动编号**:行内 **＋** 按钮创建子任务;序号自动生成(`1`、`1.1`、`1.1.1`);父任务 ▸/▾ 折叠整棵子树。
- **进度汇总**:每行进度条可点击/拖动设置;父任务进度 = 子任务递归平均,勾选父任务 = 整棵子树完成;分块与顶栏自动汇总。
- **输入联想**:输入时从已有内容联想补全(如已有 `codex`,输入 `cod` 即联想),**Tab** 确认,↑↓ 切换。
- **拖拽移动(含子树)**:任务可拖到其他分块或块内任意位置,整棵子树一起走。
- **自由调整大小**:拖分块右缘/下缘/右下角调宽高,双击边缘还原默认(360×420)。
- **主题**:浅色/深色一键切换(🌓),默认跟随系统。

## ⌨️ 快捷键

| 按键 | 作用 |
|---|---|
| Enter | 保存任务(编辑框 / 添加框) |
| Esc | 关闭联想 → 取消编辑 / 清空添加框(新建子任务取消 = 放弃创建) |

| ↑ / ↓ | 在联想候选间切换 |

## ❓ 常见问题

**打开后看板是空的?**
数据存在浏览器里,换了浏览器/电脑/路径可能读不到旧数据,用之前导出的 JSON「导入」恢复即可。

**清空浏览器缓存会丢数据吗?**
会。清理"网站数据/localStorage"会一并清掉看板数据,请先导出备份。

**拖动分块/任务没反应?**
请使用较新的主流浏览器;老浏览器(如 IE)不支持本项目用到的 Pointer Events、HTML5 Drag & Drop。

**能多人协同编辑吗?**
不能实时协同——数据在各人浏览器本地。多人使用建议:各用各的,通过导出 JSON 互相导入。

## 🛠 技术说明

- 纯原生 HTML/CSS/JavaScript,单文件逻辑,零依赖、零构建;
- 布局:白板式绝对定位(分块坐标化),任务层级用扁平 DFS 结构存储并自动修复;
- 持久化:`localStorage`,键名 `taskboard.v1`,每次操作即时保存;
- 运行环境:任何支持 Pointer Events、HTML5 Drag & Drop、CSS 变量的现代浏览器。
